## 2. SSE 消费约定（红线 7）

- **fetch + ReadableStream**（D1）：`EventSource` 不支持 POST 与 `Authorization` 头。
- **帧解析**：`SSEDecoder` 按 `\n\n` 分帧 → 取 `data:` 行拼接 → `JSON.parse` → 按 `type` 判别；跨 chunk 半包分帧由缓冲区承接；非法帧丢弃并 `console.warn`。
- **评分只来自 `score` 事件对象**：`chunk` 文本原样追加渲染，绝不解析。

## 3. 401 续期与单次重放（D2）

`streamAnswer` 内手写一次续期重放：`fetch(401) → tryRefresh() → 重放一次`，重放失败清 token 跳登录。幂等由后端 Redis 互斥锁 `interview:{id}:lock` 保证。

## 4. 断线恢复（D6）

`Chat.vue` onMounted 时 store 为空/不匹配 → `resumeFromServer(interviewId)` 调 `GET /messages`，按 `(question_index, round)` 重建气泡与双键，不落 localStorage（单一真源在服务端）。

## 5. 反污染前端断言（红线 7）

- store 层与 UI 层各一道：`chunk` 文本含 `{"score":10}`，`score` 事件为 `7.5` → 断言评分卡显示 `7.5`、气泡文本原样。
