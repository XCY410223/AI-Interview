## 三、偏差复盘（计划书 vs 实现）

| 计划书 | 实际 | 原因/结论 |
|---|---|---|
| 测试目录 `tests/schemas` / `tests/services/report` / `tests/tasks` / `tests/api` | 并入现有 `tests/unit` / `tests/integration` | 沿用仓库既有扁平约定，保持一致 |
| 结果缓存 key `report:payload:{report_id}` | `report:payload:{user_id}:{report_id}` | key 必须含 user_id，否则缓存命中会绕过归属校验（IDOR） |
| `prompts/report.py` 单文件 | `prompts/report/` 包 | 需 `v1.py` + `__init__.py` 注册表（对齐 `resume_parser` 约定） |
| WeasyPrint 版本锁定 `==x.y.z` | `>=62.3,<63`（待冒烟后锁定） | 无法在本地重建镜像做中文冒烟，留人工锁版 |
| 计划书 10 个决策点 | 3 个关键决策经用户确认（PDF 方案/自动生成/6 维契约），其余采纳计划书建议 | 收敛确认面，避免无谓打断 |
