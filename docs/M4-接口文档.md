# M4 接口文档

> 范围：JD 解析 / 真题 RAG / 题库模板 / 历史回放 / 专项练习 / Waiting List（M4 计划 §四 PR-D1）
> 统一响应错误格式：`{"code": "...", "message": "...", "data": null}`；所有需登录接口走 Bearer access token。

## 1. JD 定制

### `POST /api/v1/question-bank/jd/parse`（登录，计入 AI 限流）
贴入 JD 原文，同步解析出岗位名 + 能力项清单。

请求：
```json
{ "jd_text": "岗位描述原文，50~20000 字" }
```
响应 `200`：
```json
{
  "position_guess": "后端工程师",
  "capabilities": [
    { "name": "Kafka 消息可靠性", "category": "hard_skill",
      "keywords": ["Kafka", "消息队列"], "importance": "must" }
  ],
  "parsed_at": "2026-09-26T00:00:00Z"
}
```
错误：`422 QUESTION_BANK_JD_PARSE_FAILED`（解析失败提示重贴）、`429 AI_RATE_LIMITED`。

## 2. 真题 RAG

### `POST /api/v1/question-bank/ingest`（登录）
面经入库（文本粘贴，不做文件上传）。建作业行后下发 Celery `rag.ingest`（切片→去重→embedding→入库）。

请求：
```json
{ "company": "字节", "position": "后端", "difficulty": "medium",
  "content": "面经原文", "source_url": "https://公开链接" }
```
响应 `202`：`{ "item_id": 1, "status": "pending", "task_id": "..." }`
错误：`400 QUESTION_BANK_INVALID_SOURCE`（source_url 仅 http/https）。

### `GET /api/v1/question-bank/search`（登录）
真题检索（带 Redis 缓存 10min）。Query：`company` / `position` / `difficulty` / `top_k`(默认 8)。

响应 `200`：
```json
{ "items": [ { "id": 1, "company": "字节", "position": "后端",
               "difficulty": "medium", "content": "真题 chunk", "source_url": null } ] }
```

## 3. 题库模板（全局共享沉淀）

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/v1/question-bank/templates` | 创建模板（`position/difficulty/category/content/reference_points/tags`） |
| GET | `/api/v1/question-bank/templates` | 分页列表（可选 `position` 过滤） |
| GET | `/api/v1/question-bank/templates/{id}` | 详情 |
| PUT | `/api/v1/question-bank/templates/{id}` | 更新（全字段可选） |
| DELETE | `/api/v1/question-bank/templates/{id}` | 软删除（204） |

出题引用：`InterviewConfig.use_templates=true` 时，按岗位+难度取模板（≤5，按 usage_count 降序）注入出题并累计计数。

## 4. 历史回放

### `GET /api/v1/interviews`（登录）
面试列表（分页，归属过滤）。响应：`{ "total": N, "items": [InterviewListItem] }`。

### `GET /api/v1/interviews/{interview_id}`（登录）
回放详情：题目快照 + 逐条消息 + 报告摘要。
响应：`InterviewReplay`（`questions` / `messages` / `report_summary` / 状态与时间戳）。

### `POST /api/v1/interviews/{interview_id}/questions/{question_index}/re-evaluate`（登录，独立计费）
对某题作答重新评分。**不改原分、不改报告**——新分数以 `score` message 追加落库（`payload_json.re_evaluated=true`）。

响应：`{ "question_index": 0, "score": 8.0, "dimensions": {...}, "feedback": "..." }`

## 5. 弱项专项练习

### `POST /api/v1/practice`（登录，计入 AI 限流）
由报告弱项生成针对性练习题目包（复用出题通道）。

请求：`{ "report_id": 1, "count": 5 }`（count 1~10）
响应 `201`：`{ "practice_id": 1, "report_id": 1, "count": 5, "questions": [QuestionItem] }`
错误：`409 REPORT_NOT_READY`（报告未生成完成）。

### `GET /api/v1/practice/{practice_id}`（登录）
查询练习包（归属校验）。响应同上。

## 6. Waiting List（增长机制）

### `POST /api/v1/waiting-list`（**公开**，无需登录）
订阅等候名单。IP 限流（5 次/小时）+ 邮箱唯一防重（幂等）。

请求：`{ "email": "user@example.com" }`
响应 `201`：`{ "email": "user@example.com", "already_subscribed": false }`
错误：`422`（非法邮箱）、`429 WAITING_LIST_RATE_LIMITED`（限流）。

### `GET /api/v1/waiting-list/export`（登录，管理侧）
CSV 流式导出（`email,created_at`），**不写本地磁盘**。MVP 无角色系统，暂以登录态为门槛。
