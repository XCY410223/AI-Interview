# 报告接口文档（M3）

> 前缀：`/api/v1/reports` · 全部需登录（Bearer access token）· tag「报告」

## 状态机

```
pending ──► processing ──► completed
   ▲            │
   └────────────┘  可重试异常（retry_count+1 ≤ 3，backoff）
                │
                └──► failed   retry_count 耗尽 / 不可重试异常
```

## 错误码

| code | HTTP | 含义 |
|---|---|---|
| `REPORT_NOT_FOUND` | 404 | 报告不存在或非本人（不区分，防枚举 §11.3） |
| `REPORT_NOT_READY` | 409 | 报告未生成完成 / PDF 未就绪 |
| `INTERVIEW_NOT_FINISHED` | 409 | 面试尚未结束 |
| `AI_TIMEOUT` / `AI_OVERLOAD` | 503 | LLM 超时/过载（生成失败可重试） |

## 接口

### 1. 生成报告（幂等）

`POST /api/v1/reports`

```json
{ "interview_id": 1 }
```

- `202`：新建/重新入队 `{"report_id": 1, "status": "pending"}`
- `200`：已存在且 pending/processing/completed，直接返回既有报告
- `409`：面试未完成（`INTERVIEW_NOT_FINISHED`）
- `404`：面试不存在或非本人

> 面试结束时后端已自动投递 `report.generate`，此接口主要用于失败后「重新生成」。

### 2. 报告详情

`GET /api/v1/reports/{report_id}`

返回 `ReportDetail`（读 `report:payload:{user_id}:{report_id}` 缓存，miss 查 DB 后回填 86400s）：

```json
{
  "report_id": 1,
  "interview_id": 1,
  "status": "completed",
  "prompt_version": "1.0",
  "overall_score": 8.2,
  "grade": "良好",
  "summary": "……",
  "dimensions": [{"key": "fundamentals", "name": "基础知识", "score": 8.0, "comment": "……"}],
  "strengths": ["……"],
  "weaknesses": ["……"],
  "suggestions": ["……"],
  "hire_recommendation": "推荐",
  "question_scores": [{"question_index": 0, "round": 0, "question": "……", "score": 8.0, "feedback": "……"}],
  "answer_quality_avg": 7.5,
  "pdf_ready": true,
  "error_message": null,
  "generated_at": "2026-09-20T09:00:00Z"
}
```

### 3. 报告列表

`GET /api/v1/reports?page=1&page_size=20`

返回 `{ "total": 2, "items": [ReportListItem] }`（`page_size` 上限 100）。

### 4. 触发 PDF 导出（幂等）

`POST /api/v1/reports/{report_id}/pdf`

- `202`：已入队渲染 `{"report_id": 1, "status": "processing"}`
- `200`：已导出 `{"report_id": 1, "status": "completed"}`
- `409`：报告未生成完成

### 5. 下载 PDF

`GET /api/v1/reports/{report_id}/pdf`

- `200`：PDF 二进制，`Content-Type: application/pdf`，`Content-Disposition: attachment; filename*=UTF-8''…`
- `409`：报告未生成 / PDF 未就绪
- `404`：报告不存在或非本人

## 维度契约（前后端唯一真源）

`fundamentals(基础知识) / technical_depth(技术深度) / project_experience(项目经验) / logical_thinking(逻辑思维) / communication(表达沟通) / job_fit(岗位匹配)`

- 分数 `0~10` 一位小数，服务端 clamp
- `overall_score = 6 维均值`（一位小数），服务端计算，不接受 LLM 自报
- 等级：优秀 ≥9 / 良好 ≥8 / 合格 ≥7 / 待提升 <7
