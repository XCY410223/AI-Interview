## 四、契约偏差（需评审确认）

1. **F9 入库状态无轮询**：计划书原定「复用 `usePolling` 轮询 pending→done/failed」，但后端**无入库状态查询端点**（仅 `POST /question-bank/ingest` 返回 202 `{item_id,status,task_id}`，无 `GET /question-bank/items/{id}`）。按「契约诚实原则」**未做假轮询**，入库页仅展示 202 提交结果（作业编号 + pending 徽标 + 异步处理说明）。如需状态可见，需后端补状态查询端点（纯前端范围外）。
2. **回放跳转报告**：`InterviewReplay` 仅含 `report_summary`（无 `report_id`），回放页通过 `listReports` 按 `interview_id` 匹配 `report_id` 后再跳 `/report/:id`。
